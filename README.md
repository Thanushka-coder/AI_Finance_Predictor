# 💰 AI-Powered Personal Finance and Expense Prediction

An AI-powered personal finance application that analyzes personal expenses, identifies spending patterns, and predicts future expenses using Machine Learning.

## 🚀 Project Overview

Managing personal expenses can be difficult without proper analysis of spending patterns.

This project combines **Artificial Intelligence, Machine Learning, Data Analytics, and Financial Management** to help users understand their expenses and make better financial decisions.

The application provides an interactive **Streamlit dashboard** for analyzing financial data and generating expense predictions.

## ✨ Features

* 📊 Expense tracking and analysis
* 💰 Expense categorization
* 📈 Spending pattern analysis
* 🔮 Future expense prediction
* 🤖 Machine Learning-based prediction
* 📉 Interactive data visualizations
* 📅 Monthly expense analysis
* 🧮 Statistical analysis
* 📋 Financial summaries
* ⚡ Interactive Streamlit dashboard

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Thanushka-coder/AI_Finance_Predictor.git
```

### 2. Open the Project

```bash
cd AI_Finance_Predictor
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.

## 🔐 Security

Sensitive information should **never** be uploaded to GitHub.

Keep the following information private:

* API keys
* Database credentials
* Passwords
* Authentication tokens
* Private configuration

Use a `.env` file for sensitive configuration.

Example:

```env
API_KEY=your_api_key_here
DATABASE_URL=your_database_url_here
```

The `.env` file is excluded through `.gitignore`.
